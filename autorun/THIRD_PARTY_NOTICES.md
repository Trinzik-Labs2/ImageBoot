# Third-party notices

Owner-supplied BootSound.mp3 is separately documented in docs/boot-sound.md; inclusion does not automatically relicense it under MIT. mpg123 and its ALSA module are existing firmware dependencies referenced in place, not redistributed in the package.

CustomLogo launcher, host tooling, and renderer source are original MIT-licensed project code. The default stock-helper archive contains no third-party executable, mod library, or stock firmware. az0x-splashctl is referenced as an already-installed firmware utility, not redistributed. Owner-supplied Toxitron.png has separate provenance described in assets/SELECTED-LOGO.md.

Host build dependency: Pillow 13.0.0, HPND license (https://github.com/python-pillow/Pillow/blob/13.0.0/LICENSE). Pillow is not included in the device archive. Zig 0.14.1 is a build-time tool (https://ziglang.org/download/0.14.1/release-notes.html); the optional fallback is linked against its musl libc.

The optional direct-DRM renderer uses Linux v6.12 DRM UAPI headers as external build dependencies, not copied mod implementations. Headers and toolchain are kept outside this repository. Their notices and the musl notice are reproduced below for fallback-binary distributions.
